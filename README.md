# Kchaitanya863 Boxr

## How do I install these formulae?

`brew install kchaitanya863/boxr/<formula>`

Or `brew tap kchaitanya863/boxr` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kchaitanya863/boxr"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
